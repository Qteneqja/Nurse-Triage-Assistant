# Birchwood verbal fillers (pre-rendered audio)

This directory holds the **pre-rendered** Birchwood verbal-filler audio used by
the `/thinking` poll loop (Aurora naturalness pass, Track A). For Birchwood
calls, the loop plays a short spoken filler ("Okay, one sec.") instead of the
keyboard-typing bed — but only when the audio exists here.

It is **empty by design** in version control: the MP3s are environment-specific
(they embed the Azure Bree DragonHD voice) and must be generated by an operator
with Azure Speech credentials.

## Generate the audio

```bash
# Requires AZURE_SPEECH_KEY + AZURE_SPEECH_REGION
python -m scripts.prerender_birchwood_fillers
```

This writes `filler_0.mp3 … filler_N.mp3` (one per phrase in
`voice_naturalness.FILLER_POOL`) plus `manifest.json`.

## Fallback behaviour

If this directory has no `manifest.json` / no MP3s (e.g. a fresh deploy that
hasn't run the script), `src/utils/voice_fillers.available_filler_files()`
returns `[]` and the `/thinking` loop falls back to `typing.wav`. Healthcare
calls always use `typing.wav` regardless. Nothing here changes a triage path.
